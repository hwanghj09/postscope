PostScope v1.0.1 — 화면 문구를 줄이고 주요 작업 흐름을 개선했습니다.

- 슬로건·중복 안내 제거, 핵심 지표와 차트를 우선 배치
- 최근 7일·30일 빠른 선택, 상세 필터·추가 분석 접기
- 가져오기 취소 시 빈 작업공간 생성 방지, 입력 오류를 창 안에 표시
- 필터 적용 중 화면 조작 유지, 늦은 응답이 다른 작업공간을 덮어쓰는 문제 방지
- 히트맵 표 전환 시 시간당 단위 유지, 다운로드 후 버튼 형태 유지
- 모바일 메뉴의 배경 클릭·Escape 닫기와 터치 영역 개선

ZIP을 풀고 Windows는 `start.bat`, Linux는 `./start.sh`로 실행한 뒤 http://127.0.0.1:8765 로 접속하세요. 최초 의존성 설치에는 인터넷이 필요합니다. `SHA256SUMS.txt`로 ZIP의 무결성을 확인할 수 있습니다.

배포 파일은 소스와 실행 스크립트입니다. Python 자체 또는 독립 실행형 EXE는 포함하지 않습니다. 실제 Telegram 계정·방을 통한 인수검사는 별도로 필요합니다. 로컬 서버를 인터넷에 공개하는 웹 호스팅 배포는 포함하지 않습니다.

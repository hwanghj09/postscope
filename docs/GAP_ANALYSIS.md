# 공백 분석

웹의 **공백 분석** 메뉴에서 확인합니다. 기본 화면은 2일 이상 공백만 보여주며 ‘모든 공백’, 길이·날짜·특이도 정렬을 선택할 수 있습니다. 구간을 누르면 직전·직후 7일의 게시량 차트가 열립니다. 전역 상세 설정에서 선택한 기간·시간대·작성자·유형·집계 단위를 그대로 적용합니다.

## 집계

- **공백**: 현지 날짜의 하루 전체가 조회됐고 선택 조건에 맞는 게시물이 0건인 연속 날짜입니다. 미조회·부분 조회 날짜는 공백으로 세거나 연결하지 않습니다. 오늘이 아직 끝나지 않았다면 오늘의 0건은 공백이 아닙니다.
- **완료된 공백**: 바로 앞·뒤 날짜 모두 게시물이 확인된 구간입니다. 분석 기간이나 미조회 경계에 걸린 구간은 ‘경계 미확인’으로 표시하고 모델 학습에서 제외합니다.
- **전후 평균**: 직전·직후 7개 달력 날짜의 건수 합 / 7입니다. 0건인 날도 포함합니다. 7일이 모두 조회되지 않았거나 분석 기간 바깥이면 평균은 비워 둡니다. `4/7일 게시`는 7일 중 게시물이 있던 날짜가 4개라는 뜻입니다.
- **연속 연도 반복**: 전년·다음 해 같은 월·일을 전부 조회한 경우에만 비교합니다. 다른 완료 공백과 최소 2일(하루 공백은 1일)이 겹치면 반복으로 표시합니다. 날짜를 못 봤으면 ‘비교 불가’입니다. 2월 29일을 다른 날짜로 바꿔 비교하지 않습니다.

공백은 현재 접근 가능한 기록 기준입니다. 삭제된 게시물의 존재나 실제 활동 중단, 활동 중단의 원인을 확인하지는 않습니다.

## 머신러닝

완료됐고 전후 각각 7일이 모두 확인된 **모든 길이의 공백**으로 비지도 학습합니다. 화면의 최소 길이·정렬 변경은 학습 대상을 바꾸지 않습니다. 전역 분석 필터를 적용하면 그 조건에서 다시 계산합니다.

Isolation Forest의 입력은 다음 5개입니다.

1. `log1p(공백 일수)`
2. `log1p(이전 7일 평균)`
3. `log1p(이후 7일 평균)`
4. 인접 연도 같은 날짜에서 가장 많이 겹치는 완료 공백의 일수 / 현재 공백 일수
5. 인접 연도 비교 가능 여부(0 또는 1)

비교할 연도가 없으면 겹침 비율은 0으로 입력하지만 별도 비교 가능 변수가 0이므로 ‘반복 없음’과 구분합니다. 최소 학습 표본은 20개입니다. 표본이 적거나 모든 특성이 같으면 점수를 비워 둡니다.

트리 96개, 트리당 표본 최대 128개, 최대 깊이 `ceil(log2(표본 수))`, 시드 1729를 사용합니다. 각 노드에서 변하는 특성 하나와 분할 위치를 무작위로 고릅니다. 표준 격리 경로 길이와 잎의 표본 수 보정을 사용하며, 점수는 `100 × 2^(-평균 경로 길이 / c(표본 수))`입니다. 외부 의존성 없이 같은 Python 구현을 Actions와 브라우저에서 사용합니다.

이 점수는 다른 공백에 비해 패턴이 얼마나 다른지를 나타내는 **사후 특이도**입니다. 공백 이후 데이터를 사용하므로 미래 공백의 예측 확률·정확도·신뢰도로 해석할 수 없습니다. 연도가 모두 확보되지 않은 구간에서 반복 여부를 추정하지 않습니다.

HTML 보고서에는 공백 표가 포함됩니다. CSV/ZIP에는 `gaps.csv`와 모델 설정·표본 수를 담은 `gap_model.json`이 포함됩니다. 원본 본문·파일·인증값은 포함하지 않습니다.

## 저활동 기간과 평일·주말 비교

기본 공백 화면은 **직전 28일 평균의 20% 이하인 날이 2일 이상 이어진 기간**을 표시합니다. 기준이 되는 직전 28일은 모두 조회가 완료되어야 하며 평균에 0건인 날도 포함합니다. 구간이 시작되면 기준 평균을 고정하고, 기준을 넘거나 미조회·부분 조회 날짜를 만나면 구간이 끝납니다. 0건 기준도 메뉴에서 선택할 수 있습니다. 시작 직전 28일 평균이 0이면 저활동 여부를 판단하지 않습니다. 저활동 구간별 전후 평균·연도 비교·특이도는 기존 공백과 같은 방법으로 별도 계산합니다. CSV에는 `low_activity.csv`, `low_activity_model.json`으로 보관합니다.

평일·주말 분포는 각 시간의 게시량을 **그 그룹의 조회 완료 날짜 수**로 나눈 1일 평균입니다. 부분 조회 날짜의 게시물과 날짜는 분자·분모에서 함께 제외합니다. 조회 완료일이 없으면 값은 비워 둡니다.

요일×시간 히트맵과 표, 평일·주말 차트의 열은 **05, 06, …, 23, 00, …, 04시** 순서입니다. 히트맵에서 00~04시는 다음 날 기록입니다(월요일 행의 04시는 화요일 04시). 평일·주말 분포는 현지 달력 날짜를 기준으로 비교합니다. HTML·PNG 히트맵도 같은 순서로 저장합니다.
